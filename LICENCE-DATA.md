# Curriculum Content Licence

## Code vs Content

The **MIT licence** in this repository (see [LICENSE](LICENSE)) covers the
**code and repository structure only**. It does not cover:

- curriculum content the plugins return from the Oak Curriculum MCP, which comes
  from the Oak Open Curriculum API;
- Oak's curriculum principles, which the plugins' skills set out;
- Oak branding, including the plugin's icon. See [BRANDING.md](BRANDING.md).

## Curriculum content from the Oak Curriculum MCP

The plugins fetch curriculum content at runtime from the Oak Curriculum MCP,
which serves content from the
[Oak Open Curriculum API](https://open-api.thenational.academy/). That content
is subject to licence terms set by the API provider. At the time of writing,
curriculum lesson content provided via the API is made available under the
[Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/)
(except where otherwise stated).

No curriculum data is committed to this repository.

**Consult the upstream authoritative sources for the definitive terms:**

- [Oak Curriculum API Terms](https://www.thenational.academy/legal/terms-and-conditions-api-version)
- [Oak API Documentation Terms](https://open-api.thenational.academy/docs/about-oaks-api/terms)
- [Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/)

## Attribution

requirements.

Academy. Each skill states its own terms in its `SKILL.md` frontmatter and
lists its sources in `references/sources.md`. Where these differ from this
file, the more restrictive terms apply.
